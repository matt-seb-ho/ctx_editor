## The Core Challenge

When the analyzer sees only user messages (hard attention), it produces clean, accurate task specs
that dramatically improve downstream performance. But in realistic settings, the analyzer must see
the full conversation. When it does, the assistant's reasoning contaminates the task spec — the
analyzer unconsciously adopts the assistant's framing, assumptions, and errors.

This cheatsheet teaches the analyzer to resist contamination: to read the full conversation but
extract specifications grounded only in what the user actually stated.

## How the Cheatsheet Is Used

The cheatsheet is injected into the task spec query prompt. The analyzer reads the full conversation
(user + assistant messages) and must produce a clean task specification as if it had only seen user
messages. The cheatsheet guides the analyzer's internal reasoning process to achieve this.
